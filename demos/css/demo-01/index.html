Lenguajes de la Web: HTML, CSS

El lenguaje CSS se emplea para dar estilo a la página, permitiendo controlar aspectos como colores, fuentes, márgenes y disposición de los elementos.

En esta demo incluimos ejemplos de las tres formas de usar CSS desde HTML

  • CSS Inline: Se aplica directamente a un elemento HTML mediante el atributo style.

    Example

  • CSS Interno: Se incluye dentro de la sección <head> del HTML utilizando la etiqueta <style>.
  • CSS Externo: Se define en un archivo separado (como styles.css) y se vincula al HTML mediante la etiqueta <link>.
