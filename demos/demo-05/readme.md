# HTML5

HTML5 aparece en 2008 como una evolución de HTML4.01, que se había estancado en 1999. El objetivo de HTML5 era modernizar el lenguaje, adaptarlo a las necesidades actuales y mejorar la experiencia de desarrollo web. 

Clave: Semántica

HTML5 introduce nuevas etiquetas semánticas que permiten estructurar el contenido de manera más clara y significativa. Estas etiquetas incluyen `<header>`, `<nav>`, `<section>`, `<article>`, `<aside>` y `<footer>`. Estas etiquetas ayudan a los desarrolladores a organizar el contenido de una página web de forma lógica, lo que mejora la accesibilidad y el SEO.

## ARIA - Accessible Rich Internet Applications

- Role: Define el tipo de elemento o su función en la página.

- Roles:
  - Landmark: `<header>`, `<nav>`, `<main>`, `<footer>`
