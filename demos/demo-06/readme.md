# HTML: Embedding...


Elementos "Embedding": se refieren a la capacidad de incluir contenido externo dentro de un documento HTML. Esto se puede lograr utilizando varias etiquetas y técnicas, como `<iframe>`, `<embed>`, `<object>`, entre otras. Estas etiquetas permiten integrar contenido multimedia, documentos, aplicaciones web, y otros recursos externos directamente en una página web.
